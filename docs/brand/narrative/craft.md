# 看不见的准备

> 有些功夫不必挂在嘴边叫卖，但当你想确认的时候，每一处都应该经得起细看。

走到这一页的人，通常心里已经冒出了几个最实在的问题：_话说得挺好听，但你们真靠得住吗？食材从哪来？价格会不会玩套路？临时出状况怎么办？_

下面不讲故事，只按事实交代我们的底盘与边界。

::: info 建设状态说明
以下供给机制、溯源展示与小程序能力属于当前规划与推进中的服务蓝图，部分环节尚待在履约系统中逐项落实。我们只在能力真正落地后，才将其作为对外服务承诺。
:::

## 1. 供给怎么组织：两条路径，绝不混淆

我们不走「线上囤一堆肉慢慢卖」的路子（线上不为还没产生的订单预留待售肉品），而是按真实需求来准备，并且把两条供给的来源说得清清楚楚、绝不混用：

- **提前预约（主线）**：你提前提出部位、数量和所需时间，平台按订单匹配**大石 4A 屠宰场自有产线**进行分割与配送。这条链路以全流程可追溯为建设目标，让来源、分割和订单信息一一对应。
- **临时起意（补充）**：对于计划之外的需求，拟通过线下菜市场调配，或由专人前往屠宰场一级市场挑选配货。临时采购无法像自有产线预约一样做到全流程监控，因此在来源说明上会明确区分，绝不拿预约链路的溯源说法去套临时采买。

预约订单若因异常最终无法正常履约，对应肉品拟转入线下菜市场肉档分流销售——这是运营侧的损耗去向安排，不代表线上的无条件退改承诺。

## 2. 价格怎么定：当日固定挂牌价

定价只守一条朴素原则：**同一天内，挂牌价固定。**

- 你在当天不同时间下单，看到的是同一个实在价；即使当天上游采购成本波动，也不在一天内反复调价，日内波动由经营方承担。
- 除前期引流外，不设置优惠券、满减、凑单等消耗精力的复杂规则，不让你为「什么时候买最划算」分心。
- 同样把话说在前面：**日内固定挂牌价不等于跨日固定价或跨日价保**，不同日期之间的定价规则仍需结合实际运营明确。

## 3. 变化发生时：诚实的边界比好听的许诺更重要

品牌愿意回应变化，但不等于空口答应「两小时必达」或「随时无条件改约」。真实的分寸落在具体细节里：

- **遇到选好的时段刚满额**：不靠一句客套的「抱歉」敷衍，而是保留你已填的信息，只给出真实可选的替代时段；若更换选项会影响肉品日期或总价，先把差异摆清楚，再由你决定。
- **遇到状态未确认**：付款状态或新时段未落定前，界面绝不误导为「未扣款」或「改约成功」。
- **责任归属清晰**：因切割、出库、食安与配送限制而无法变更时，坦诚告知限制与原订单去向；若问题由我们造成，由我们承担相应责任。

## 4. 还没定稿的部分，我们如实留白

一个有深度的品牌，不需要用半成品假装已经完成：

- **品牌名与主标志尚未定稿**：此前围绕「折叠面」「太平鸟」「纸翻花」做过多轮意象与命名探索，留下了重要的审美证据与反例，但尚无最终胜出的主名与主标。
- **视觉与字体仍在真实验证中**：金黄与橙红的暖色方向、四角色字体组合（香萃潮汐宋、FandolSong、Instrument Serif、Cormorant Garamond D3 原件）已完成原型对比，但印刷色值、窄屏长标题、价格数字回退与实物肉品标签仍需联合实测。
