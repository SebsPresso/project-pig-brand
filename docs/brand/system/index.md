# 品牌系统

先读[品牌的故事](../)，再回来找具体判断。这里的结构是为了以后能改：例如履约条件变了，就回查承诺与订单提醒，不必因此重选字体或重写整个品牌。

| 要回答的问题                                                     | 去哪里找                 |
| ---------------------------------------------------------------- | ------------------------ |
| 我们为谁做准备，又把什么留给人自己决定？                         | [B1 · 品牌定义](./b1/)   |
| 别人不知道故事，也能从一句话、一张图和一个动作里感到这份分寸吗？ | [W3 · 比较创意](./w3/)   |
| 名字、标志、标签和订单提醒，放在一起还像同一家吗？               | [B2 · 品牌表达](./b2/)   |
| 顾客需要帮助时，界面上说的和实际能做的对得上吗？                 | [B3 · 体验与履约](./b3/) |
| 换一个人来接手，他知道该用哪版、怎样做、什么时候要改吗？         | [B4 · 交付与维护](./b4/) |

W3 是从定义走向表达时的一次比较，不是额外一层。具体哪版能用，去各页看记录。同一件作品可以是有用的参考，仍然没到能定稿或印出来的程度。
